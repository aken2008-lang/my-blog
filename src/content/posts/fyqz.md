# 复议前置（必须先复议，不服才能起诉）【依据：2023《行政复议法》第 23 条】

> 一句话：**复议前置是例外，原则上可以选择复议或直接起诉**

1. **对当场作出的行政处罚决定不服**

  （简易程序当场处罚，如 200 元以下当场罚款）
2. **行政机关的决定侵犯你已经依法取得的自然资源所有权 / 使用权**

  ✅要点：你**已经有合法权属（土地证、林权证等）**，政府确权裁决侵害该权利；

  ❌排除：自然资源相关的处罚、强制措施、征地补偿，这些不用前置
3. **行政不作为（不履行法定职责）**

  申请履职（保护人身财产权、许可、社保给付等），机关不答复、不履行；

  ⚠️注意：机关直接作出**不予许可、不予给付的拒绝决定**，不属于这类前置，可以直接起诉
4. **申请政府信息公开，行政机关不予公开（含不予公开答复、逾期不答复）**
5. **法律、行政法规另行规定的其他复议前置（考试高频）**
  - ✅**纳税争议（征税行为）**：是否纳税、谁纳税、税额、税率、滞纳金等； 👉易错：**税务处罚、保全、强制执行，不是前置，可以直接起诉**；且纳税争议还要先缴税 / 提供担保才能复议（《税收征管法》88 条）
  - ✅其他单行法规定：反垄断相关决定、审计决定等

## 重要提示

- 复议前置案件，**不能直接起诉**；直接起诉法院会不予受理 / 驳回起诉
- 复议机关不受理、逾期不作复议决定，此时才可以向法院起诉
